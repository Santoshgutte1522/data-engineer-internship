# Task 2: Hands-On Data Lab Implementation

Data Engineer Internship, Task 2.

## What this covers
- Environment setup: Python, Jupyter (Google Colab), NumPy, Pandas, Matplotlib, Seaborn
- Data inspection: shape, data types, summary statistics, missing values
- Data manipulation: filtering, sorting, new columns, groupby
- Visualization: bar chart, histogram, scatter plot, line chart, box plot
- Basic analysis: correlation and group comparisons

## Dataset
Seaborn built-in restaurant `tips` dataset (244 bills, 7 columns).

## Files
| File | Description |
|------|-------------|
| `Task2_Data_Lab.ipynb` | Colab notebook with all code, outputs and charts |
| `Task2_Report.docx` | Written report with explanations |

## How to run
1. Open the notebook in Google Colab or Jupyter.
2. Run all cells from top to bottom.
3. Libraries: numpy, pandas, matplotlib, seaborn (already available in Colab).

## Key results
- Correlation between bill and tip: 0.68
- Average tip: 16.08% of the bill
- Busiest day: Saturday
- Weekend bills are higher than weekday bills
