# Task 1: Data Science Fundamentals Assessment

Data Engineer Internship, Task 1.

## What this covers
- Python basics: variables, data types, operators, conditions, loops, functions
- Collections and file handling: lists, tuples, dictionaries, sets, reading and writing files
- Statistics: mean, median, mode, variance, standard deviation, percentiles, probability, correlation
- Data types: numerical, categorical, ordinal, datetime and text data in pandas
- Best practices: clean code, reproducibility (random seed), handling duplicates and missing values

## Files
| File | Description |
|------|-------------|
| `Task1_DS_Fundamentals.ipynb` | Colab notebook with all code and outputs |
| `Task1_Report.docx` | Written report with explanations |

## How to run
1. Open the notebook in Google Colab or Jupyter.
2. Run all cells from top to bottom.
3. Libraries used: numpy, pandas (already available in Colab).

## Key results
- Sample marks (15 students): mean 79.2, median 82, mode 90, std 14.72
- Correlation between study hours and marks: 0.94
- Missing value filled with the median and duplicates removed in the best practices cell
